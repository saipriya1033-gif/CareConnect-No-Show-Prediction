# CareConnect – Patient Appointment Management and No-Show Prediction

## Project Overview
CareConnect is a patient appointment management project that combines a Streamlit application with a Machine Learning model to predict the likelihood of patients missing scheduled medical appointments.

## Features
- Patient appointment information management.
- Machine Learning-based appointment no-show prediction.
- Data preprocessing and feature engineering.
- Interactive Streamlit interface.
- Prediction using a trained Random Forest classifier.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Project Structure
- `app.py` – Streamlit application.
- `ML/train_model.py` – Machine Learning model training.
- `careconnect_model.pkl` – Saved trained model.

## How to Run Locally
1. Clone this repository.
2. Install the required dependencies.
3. Run the application using:

```bash
streamlit run app.py
```
